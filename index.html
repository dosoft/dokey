Switch language.
One key at a time.

Left Shift selects English. Right Shift selects Russian. No cycling, no guessing.

Download for WindowsBrowse project

WHY DOKEY?

Standard Windows shortcuts make you remember which language is active. DOKEY assigns one layout to each Shift key: Left Shift for English, Right Shift for Russian. Even if you press the same Shift again, nothing bad happens. Swap the assignments in Settings.

I first used this method back in DOS with KeyRus, and later in Windows with Punto Switcher. But at some point Punto Switcher became too heavyweight for such a small task, so I had to write a small dedicated utility.

FEATURES

LEFT SHIFT
Selects English directly, without cycling through layouts.
RIGHT SHIFT
Selects Russian directly. Repeating the key changes nothing.
KEYS
Letters, arrows, mouse clicks and modifier combinations keep their normal behavior.
TRAY
Shows the active window's current EN or RU layout.
SETTINGS
Swap key assignments and adjust the maximum press duration.
UPDATES
Checks GitHub Releases and notifies you when a new version is available.
PRIVACY
No telemetry or analytics. Distributed under the MIT License.

ACTIVATION CONDITIONS

The layout changes only after a clean Shift press:

  • no other key is pressed at the same time (Ctrl, Alt, Win, letters, arrows, and so on);
  • no mouse button is clicked while Shift is held;
  • if Shift is held for longer than 300 ms (configurable), the layout is not changed.

Normal Shift behavior — including Shift+letter, Shift+arrow, and Shift+click — is unaffected.

REQUIREMENTS

  • Windows 10 or 11.
  • RU (0419) and EN (0409) layouts installed in Windows language settings.

INSTALL

  1. Download dokey-win-Setup.exe from Releases.
  2. Run the per-user installer. No separate .NET installation is required.
  3. DOKEY starts in the tray. Open Settings to change assignments or auto-start.

Note: Windows SmartScreen may warn that the installer is unsigned. To proceed with the installation, click “More info” → “Run anyway”.

KNOWN LIMITATIONS

  • Elevated windows (UAC): if the active window runs as administrator while DOKEY does not, layout switching will not work in that window. Run dokey.exe as administrator as well. The built-in autostart does this automatically.
  • Only two layouts are supported: RU (0419) and EN (0409).
